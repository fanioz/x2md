# Fully pinned dependency lock for the x2md Apify Actor.
#
# The scraping core (x2md.py) is stdlib-only, so the Apify SDK is the single
# direct dependency. Everything below it is pinned too, because two of its
# transitive dependencies ship breaking changes on a floating version and
# crash `from apify import Actor` at import time:
#
#   pydantic      -- 2.12 turned Field(default=..., default_factory=...) into a
#                    hard TypeError; crawlee 0.6.12 still emits that pair.
#   browserforge  -- 1.2.4 dropped browserforge.download.DATA_FILES, which
#                    crawlee's _browserforge_workaround still reads.
#
# Both are unconstrained upstream, so an unpinned build installs the latest
# release and the Actor dies before main() runs. Regenerate with:
#
#   python3 -m venv .venv && .venv/bin/python -m pip install apify==2.7.3 \
#       'pydantic<2.12' browserforge==1.2.3
#   .venv/bin/python -c 'from apify import Actor'   # must exit 0
#   .venv/bin/python -m pip freeze | grep -Ev '^(pip|setuptools)=='
