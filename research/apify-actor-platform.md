## 1. Platform Resource Limits

### Memory
- **Default memory allocation**: 128 MB (Free/Starter plans).
  *Source: [Account Limits](https://docs.apify.com/account/limits.md#actor-runtime-limits)*
- **Maximum memory allocation**:
  - Free plan: **16,384 MB**
  - Starter plan: **32,768 MB**
  *Source: [Account Limits](https://docs.apify.com/account/limits.md#actor-runtime-limits)*
- **Memory per CPU core**: 4,096 MB.
  *Source: [Account Limits](https://docs.apify.com/account/limits.md#actor-runtime-limits)*

### Timeout
- **Build timeout**: 1,800 seconds (30 minutes).
  *Source: [Account Limits](https://docs.apify.com/account/limits.md#actor-runtime-limits)*
- **Run timeout**: Not explicitly documented. Assume default is **30 minutes** (aligns with build timeout).
  *Unverified: Exact run timeout not specified in docs.*

### Budgeting for Thread-Enumeration + Media-Download Runs
- **Dynamic memory adjustment**: Use [Dynamic Actor Memory](https://docs.apify.com/actors/development/actor-definition/dynamic-actor-memory.md) to auto-scale memory based on input size.
- **Performance optimization**:
  - Use Docker layer caching to reduce build time.
  - Batch jobs to minimize overhead.
  *Source: [Actor Performance](https://docs.apify.com/actors/development/performance.md)*

## 2. Apify Proxy

### Store Policy Requirements
- **Not explicitly mandatory** for scraping Actors, but **strongly recommended** to avoid IP-based blocking.
  *Source: [Anti-scraping protections](https://docs.apify.com/academy/anti-scraping.md)*

### Available Proxy Types
| Type | Use Case | Notes |
|------|----------|-------|
| **Datacenter Proxy** | Basic scraping, fast/cheap | IP rotation for datacenter IPs |
| **Residential Proxy** | High anonymity | Human IPs, least likely to be blocked |
| **Google SERP Proxy** | Localized search results | Specialized for Google SERP scraping |
| **Unblocker** | Bypass anti-bot systems | Smart routing for Cloudflare, etc. |
*Sources: [Proxy Overview](https://docs.apify.com/proxy.md), [Datacenter Proxy](https://docs.apify.com/proxy/datacenter-proxy.md), [Residential Proxy](https://docs.apify.com/proxy/residential-proxy.md), [Google SERP Proxy](https://docs.apify.com/proxy/google-serp-proxy.md), [Unblocker](https://docs.apify.com/proxy/unblocker.md)*

### API Endpoints (e.g., `fxtwitter`)
- **No explicit requirement** for Apify Proxy, but **recommended** if the API enforces rate limits or IP-based restrictions.
  *Source: [Proxy Management](https://docs.apify.com/sdk/js/docs/concepts/proxy-management.md)*
- **Actionable**: Use **Residential Proxy** for endpoints with strict anti-bot measures (e.g., Twitter/X).

### Monetization Setup (Pay Per Event)

#### Definition of an "Event"
- A **specific, measurable action** triggered by the Actor (e.g., processing an item, calling an API).
  *Source: [Pay-per-event pricing model](https://docs.apify.com/actors/publishing/monetize/pay-per-event.md#about-events)*
- **Synthetic events** (predefined by Apify):
  - `apify-actor-start`: Covers first 5 seconds of compute.
  - `apify-default-dataset-item`: Charges per default dataset item.
  *Source: [Synthetic Events](https://docs.apify.com/actors/publishing/monetize/pay-per-event.md#synthetic-events)*

#### Pricing Approval
- **Set by Actor owner** via [monetization setup](https://docs.apify.com/actors/monetize/set-up-monetization.md).
- **Profit formula**: `profit = (0.8 * revenue) - platform costs` (80% revenue share).
  *Source: [Calculate Your Profit](https://docs.apify.com/actors/publishing/monetize/pay-per-event.md#calculate-your-profit)*
- **Testing**:
  - Use `ACTOR_MAX_TOTAL_CHARGE_USD` (env var) to respect user spending limits.
  - Test with invalid inputs to adjust validation logic.
  *Source: [Set Pricing for PPE Actors](https://docs.apify.com/actors/publishing/monetize/pay-per-event.md#set-pricing-for-ppe-actors)*

#### Constraints for Pay Per Event
1. **Primary event**: Must be defined (represents main value).
2. **Avoid negative profit**:
   - Enable `apify-actor-start` (recommended).
   - Set memory limits (`minMemoryMbytes`, `maxMemoryMbytes` in `actor.json`).
3. **Transparency**: Keep pricing simple (fewer events = clearer costs).
4. **Idempotency**: Required to prevent duplicate charges (handled by Apify SDKs).
5. **Graceful shutdown**: Charge for work done during `aborting` event (30-second window).
*Sources: [Best Practices](https://docs.apify.com/actors/publishing/monetize/pay-per-event.md#best-practices), [Handle Graceful Shutdown](https://docs.apify.com/actors/publishing/monetize/pay-per-event.md#handle-graceful-shutdown)*
